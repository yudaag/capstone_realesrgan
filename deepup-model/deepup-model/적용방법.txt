1. GitHub 저장소에서 기존 deepup-model 폴더를 백업합니다.
2. 기존 deepup-model 폴더의 내용을 이 폴더 내용으로 교체합니다.
3. GitHub에 커밋하고 push합니다.
4. GitHub Actions에서 Push model to Replicate를 실행합니다.
5. Replicate 모델의 새 Version ID를 복사합니다.
6. Cloudflare Worker의 REPLICATE_VERSION 값을 새 Version ID로 교체합니다.
7. Worker를 다시 배포한 뒤 작은 PNG 파일로 먼저 테스트합니다.

주의: best_proposed_realesrgan_div2k.pth 파일은 GitHub에 올리지 않습니다.
cog.yaml이 R2에서 내려받고 SHA-256으로 동일한 파일인지 확인합니다.
