# DeepUp 소스 코드

Depth 기반 이미지·영상 화질 개선 캡스톤 프로젝트 웹사이트입니다.

## 실행 환경

- Node.js 22.13 이상
- npm

## 로컬 실행

```bash
npm install
npm run dev
```

실행 후 브라우저에서 `http://localhost:3000`을 엽니다.

## 배포용 빌드

```bash
npm run build
```

## 주요 폴더

- `app/`: 메인, 로그인, 관리자 화면 및 인증 API
- `components/`: 프로필과 테마 전환 UI
- `lib/`: 데이터베이스·비밀번호 처리 코드
- `db/`, `migrations/`: 회원 데이터베이스 구조
- `public/`: 사이트 이미지와 발표 영상
